# Lessonroom 03 — ระบบนิเวศ & ต้นพิงอาศัย

## Production brief

- **Lesson:** 03 — HABITAT & HOST PLANTS
- **Title:** ระบบนิเวศ & ต้นพิงอาศัย
- **Target duration:** 3:00–3:30 นาที
- **Format:** 16:9, 1920×1080, Motion Graphic + ภาพ/วิดีโอจริงเมื่อมีฟุตเทจ
- **Tone:** เรียบ สงบ เป็นวิชาการแต่เข้าใจง่าย สอดคล้องกับหน้าห้องเรียนรู้ปัจจุบัน
- **Visual palette:** น้ำตาลครั่ง `#8f3328`, ครีม `#f3eadb`, ขาวนวล และเขียวธรรมชาติ
- **Existing page background:** `/Lessonroom_Ecosystem.jpeg`
- **Video asset placeholder:** `/lac-habitat.mp4`

## Learning outcomes

ผู้เรียนควรสามารถ:
1. เห็นองค์ประกอบหลักของระบบที่เกี่ยวข้องกับครั่ง
2. เข้าใจความสัมพันธ์ระหว่างแมลงครั่งกับต้นพิงอาศัย
3. เชื่อมโยงบทบาทของน้ำเลี้ยงและสภาพแวดล้อมกับการเจริญเติบโต

## Core message

> แมลงครั่ง + ต้นพิงอาศัย + น้ำเลี้ยง + สภาพแวดล้อม = ระบบที่สัมพันธ์กัน

## Motion direction

1. ใช้ **slow zoom / parallax** กับภาพธรรมชาติ เพื่อให้รู้สึกเหมือนกำลังสำรวจระบบนิเวศ
2. ใช้ **เส้นเชื่อม (connector lines)** เป็นภาษาหลักของเรื่อง เพื่อสื่อว่าองค์ประกอบต่าง ๆ มีความสัมพันธ์กัน
3. ใช้ **highlight circle** เฉพาะจุดที่กำลังอธิบาย ไม่ใช้เอฟเฟกต์ถี่จนรบกวนการเรียนรู้
4. Transition หลักเป็น `fade`, `zoom-in`, `line-draw` และ `cross dissolve`
5. ตัวอักษรภาษาไทยต้องอ่านได้ชัดบนพื้นภาพ และไม่วางข้อมูลสำคัญชิดขอบจอ

## Sound direction

- Background music: ambient / documentary เบา ๆ ไม่กลบเสียงบรรยาย
- SFX: เสียงธรรมชาติบาง ๆ ตอนเปิดเรื่อง
- ใช้ soft whoosh สำหรับเส้นเชื่อมและการเปลี่ยน scene
- ลดดนตรีลงประมาณ 20–30% ในช่วง key fact และ takeaway
